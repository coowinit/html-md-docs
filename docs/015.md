# 1. 什么是 SQLite

SQLite 是一种轻量级关系型数据库。

它最大的特点之一：

> 整个数据库可以保存在一个文件中。

例如：

```text
database/app.db
```

不需要单独启动：

```text
MySQL Server
MariaDB Server
```

因此特别适合：

```text
学习
本地工具
小型网站
内部系统
单机应用
原型项目
```

---

# 2. SQLite 和 JSON 最大区别

JSON：

```text
PHP
↓
读取整个文件
↓
转换成数组
↓
自己处理搜索、排序、修改
↓
整体写回
```

SQLite：

```text
PHP
↓
SQL
↓
数据库自己处理
```

例如：

```sql
SELECT *
FROM products
ORDER BY id DESC;
```

数据库会帮我们完成查询。

---

# 3. PDO 是什么

PDO：

```text
PHP Data Objects
```

可以把它理解为 PHP 提供的一套统一数据库访问接口。

例如：

```text
PHP
↓
PDO
├── SQLite
├── MySQL
└── 其他 PDO 驱动
```

这也是我们选择：

```text
PDO + SQLite
```

而不是只学习 SQLite 专用函数的重要原因。

---

# 4. 创建 PDO 连接

本实验：

```php
$databaseFile = __DIR__
    . '/database/app.db';

$dsn = 'sqlite:' . $databaseFile;

$pdo = new PDO($dsn);
```

核心：

```text
sqlite:
```

告诉 PDO：

> 我要连接 SQLite。

后面的：

```text
database/app.db
```

是数据库文件位置。

---

# 5. DSN 是什么

DSN 可以简单理解为：

```text
数据库连接描述
```

SQLite：

```text
sqlite:/path/app.db
```

以后 MySQL 会看到类似：

```text
mysql:host=localhost;dbname=test
```

虽然格式不同，但：

```text
PDO
```

的整体使用思想一致。

---

# 6. __DIR__

本实验使用：

```php
__DIR__
```

确保数据库路径从当前 PHP 文件目录开始计算。

于是：

```php
__DIR__ . '/database/app.db'
```

可以稳定指向数据库文件。

# 7. PDO 错误模式

本实验设置：

```php
$pdo->setAttribute(
    PDO::ATTR_ERRMODE,
    PDO::ERRMODE_EXCEPTION
);
```

表示：

> 数据库发生错误时，通过异常明确报告错误。

学习和开发阶段非常有帮助。

---

# 8. 默认读取关联数组

本实验：

```php
$pdo->setAttribute(
    PDO::ATTR_DEFAULT_FETCH_MODE,
    PDO::FETCH_ASSOC
);
```

所以查询结果类似：

```php
[
    'id' => 1,
    'name' => 'Product A',
    'price' => 20,
]
```

于是可以：

```php
$product['name']
```

这和前面学习的 PHP 关联数组完全连接起来了。

CREATE TABLE IF NOT EXISTS products (

    model TEXT NOT NULL,

# 10. id

```sql
id INTEGER PRIMARY KEY AUTOINCREMENT
```

代表：

```text
整数
+
主键
+
自动增长
```

新增记录时通常不需要手工填写 ID。

例如：

```text
1
2
3
4
...
```

# 11. TEXT

```sql
name TEXT NOT NULL
```

表示：

```text
name
↓
文本字段
↓
不能为空
```

SQLite 使用：

```text
TEXT
```

保存字符串数据。

---

# 12. REAL

```sql
price REAL
```

表示浮点数。

本实验用于价格。

在真实财务系统中，金额字段的数据类型设计需要更谨慎；这里仅用于数据库基础学习。

---

# 13. IF NOT EXISTS

```sql
CREATE TABLE IF NOT EXISTS
```

意思是：

```text
表不存在
↓
创建

表已经存在
↓
不重复创建
```

因此页面每次访问都执行这段代码，也不会一直重复创建表。

---

# 14. exec()

本实验：

```php
$pdo->exec($sql);
```

适合执行：

```text
CREATE TABLE
INSERT
UPDATE
DELETE
```

等不需要直接读取结果集的 SQL。

---

# 15. 为什么本章 INSERT 直接用 exec()

本实验插入的是：

```text
程序内部写死的固定测试数据
```

没有用户输入。

因此为了保持本章重点简单，先使用：

```php
exec()
```

后面会专门研究：

```text
prepare()
execute()
参数绑定
SQL 注入
```

当 SQL 中包含用户输入时，不能简单把输入拼接进 SQL 字符串。

# 16. query()

读取数据：

```php
$pdo->query(
    'SELECT * FROM products'
);
```

`query()` 执行 SQL 后，会得到：

```text
PDOStatement
```

然后可以继续获取结果。

---

# 17. fetchColumn()

本实验先查询：

```sql
SELECT COUNT(*)
FROM products
```

然后：

```php
fetchColumn()
```

直接取得：

```text
记录数量
```

如果数量是：

```text
0
```

才写入测试数据。

这样刷新页面不会重复插入三条产品。

---

# 18. SELECT

读取产品：

```sql
SELECT
    id,
    name,
    model,
    price,
    created_at
FROM products
ORDER BY id ASC
```

可以理解为：

```text
从 products 表
↓
取这些字段
↓
按照 id 从小到大排列
```

---

# 19. fetchAll()

PHP：

```php
$products = $statement->fetchAll();
```

得到：

```text
多条数据库记录
↓
PHP 多维数组
```

结构类似：

```php
[
    [
        'id' => 1,
        'name' => '...',
    ],
    [
        'id' => 2,
        'name' => '...',
    ],
]
```

这正好对应前面的：

```text
02 数组
04 foreach
```

# 20. 数据库查询结果如何显示

最后：

```php
foreach ($products as $product)
```

于是完整链路：

```text
SQLite
↓
PDO
↓

↓
PHP Array
↓
foreach
↓

```

这就是 PHP 动态数据库页面最核心的结构之一。

# 21. app.db 是什么

```text
database/app.db
```

不是：

```text
TXT
JSON
PHP
```

而是 SQLite 自己的二进制数据库文件。

不能使用普通文本编辑器直接编辑。

可以使用：

```text
DB Browser for SQLite
SQLite CLI
各种数据库管理工具
```

查看。

# 22. 如果删除 app.db 会怎样

本实验代码连接：

```text
sqlite:database/app.db
```

如果数据库文件不存在，并且目录有写权限，SQLite 可以创建新的数据库文件。

随后：

```text
CREATE TABLE IF NOT EXISTS
```

创建：

```text
products
```

最后发现表为空：

```text
插入三条测试数据
```

所以这个实验具有一定的“自动初始化”能力。

---

# 23. 数据库目录权限

PHP 必须可以写入：

```text
database/
```

否则 SQLite 无法：

```text
创建数据库
写入记录
更新数据库
```

部署服务器时如果出现：

```text
attempt to write a readonly database
```

通常需要检查：

```text
数据库文件权限
database 目录权限
PHP 运行用户
```

---

# 24. 一个重要的生产环境安全点

本实验为了方便学习，把：

```text
database/
```

放在项目目录中。

真实网站更推荐：

```text
把数据库放到 Web 根目录之外
```

如果必须放在公开目录内，则应该通过服务器配置禁止浏览器直接下载：

```text
.db
.sqlite
```

文件。

这个问题属于部署安全，而不是 PDO 本身。

# 25. PDO + SQLite 与 PDO + MySQL

SQLite：

```php
$pdo = new PDO(
    'sqlite:database/app.db'
);
```

以后 MySQL：

```php
$pdo = new PDO(
    'mysql:host=localhost;dbname=test',
    $username,
    $password
);
```

连接方式不同，但很多后续操作仍然是：

```text
prepare
execute
fetch
fetchAll
```

所以先学 PDO + SQLite，非常适合建立数据库基础。
