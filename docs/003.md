## 1. if / elseif / else

最基本的条件判断：

```php
if ($stock <= 0) {
    echo '缺货';
} elseif ($stock <= 10) {
    echo '库存紧张';
} else {
    echo '库存充足';
}
```

可以理解为：

```text
如果条件 A 成立
    执行 A

否则如果条件 B 成立
    执行 B

否则
    执行默认逻辑
```

本实验用它判断：

- 库存状态
- 价格级别

## 2. 比较运算符

PHP 中常见的比较运算符：

```text
==    值相等
===   值和类型都相等
!=    不相等
!==   值或类型不相等
>     大于
<     小于
>=    大于等于
<=    小于等于
```

实际开发中，能使用严格比较时，通常优先考虑：

```php
===
```

例如：

```php
$status === 'sale'
```

## 3. switch

当一个变量可能对应多个固定状态时，可以使用：

```php
switch ($status) {
    case 'sale':
        echo '正常销售';
        break;

    case 'new':
        echo '新品';
        break;

    default:
        echo '未知状态';
}
```

本实验中使用 `switch` 处理：

```text
sale
new
coming
offline
```

这些固定的产品状态。

---

## 4. 三元运算符

三元运算符适合非常简单的二选一：

```php
$result = $stock > 0 ? '可以购买' : '暂不可购买';
```

结构：

```text
条件 ? 条件成立时的值 : 条件不成立时的值
```

它适合：

- 有货 / 缺货
- 是 / 否
- 显示 / 隐藏
- 开启 / 关闭

但如果判断逻辑较复杂，应优先使用普通的 `if`。

---

## 5. 逻辑运算符

### AND

PHP 可以写：

```php
&&
```

例如：

```php
$rating >= 4.5 && $stock > 0
```

代表：

```text
评分达到要求
并且
库存大于 0
```

两个条件必须同时成立。

### OR

```php
||
```

只需要其中一个条件成立。

### NOT

```php
!
```

用于取反：

```php
!$enabled
```

## 6. PHP 模板中的条件判断

PHP 很常见的一种模板写法：

```php
<?php if ($stock > 0): ?>

    <p>有货</p>

<?php else: ?>

    <p>缺货</p>

<?php endif; ?>
```

这种写法在 HTML 模板中通常比大量花括号更容易阅读。

以后在 WordPress 主题中，会经常看到类似代码。

---

## 7. 与 WordPress / WooCommerce 的关系

WordPress 主题中经常会看到：

```php
if (have_posts()) {
    // ...
}
```

或者：

```php
if (has_post_thumbnail()) {
    // ...
}
```

WooCommerce 中也会根据产品状态判断：

```text
是否有库存
是否可购买
是否促销
是否为特色产品
产品类型是什么
```

本质上都离不开：

```text
数据
↓
条件判断
↓
决定执行哪一段代码
```
