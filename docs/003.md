# 更新日志

## 5.2.7 版本发布 🚀（2026-07-17）

- 修复已知问题，优化用户体验。

## 5.2.3 版本发布 🚀（2026-07-15）

- 新增分享功能，支持分享任务和产物，可以一键生成链接分享给好友。
- 优化紧凑模式下的聊天输入工具栏，并在消息发送后恢复输入框高度，提升小窗口下的使用稳定性。
- 修复弱网断连后的会话恢复问题，确保下一条提示词能够正常继续执行。
- 修复多设备消息同步问题，以及会话丢失后的恢复问题。
- 修复快速切换或重新连接时误报连接器失败，以及重复显示连接成功通知的问题。
- 修复切换项目任务后工具调用记录不显示，以及进行中任务筛选状态闪烁的问题。
- 修复自定义专家及专家团队成员映射异常、默认提示词错误，以及无效配置可能导致程序异常的问题。
- 修复流式内容重复、消息分组异常，以及取消状态显示错误的问题。
- 修复 Windows 端无法从结果中打开文件，以及部分弹出菜单无响应的问题。

### 本次版本重点

这一版主要围绕稳定性和小窗口体验进行优化，没有改变原有任务工作流。
