# 实验 04：PHP 循环生成 HTML 内容

本实验学习 PHP 中三种常见循环方式，并重点理解 PHP 如何根据数据批量生成重复 HTML 内容。

## 实验目标

完成本实验后，应能够理解：

- `for`
- `while`
- `foreach`
- 循环计数
- `$index + 1`
- 如何根据数组自动生成多个 HTML 卡片
- 为什么重复内容不应该手工复制大量 HTML

## 1. for 循环

`for` 很适合已知循环次数的场景。

```php
for ($i = 1; $i <= 5; $i++) {
    echo $i;
}
```

可以拆成三个部分理解：

```text
$i = 1
↓
从 1 开始

$i <= 5
↓
只要没有超过 5 就继续

$i++
↓
每次循环后增加 1
```

因此最终执行：

```text
1
2
3
4
5
```

---

## 2. while 循环

`while` 的核心是：

```text
只要条件成立
就一直重复执行
```

例如：

```php
$count = 1;

while ($count <= 5) {
    echo $count;

    $count++;
}
```

这里必须注意：

```php
$count++;
```

如果忘记让条件发生变化，就可能形成无限循环。

---

## 3. foreach 循环

处理数组时，`foreach` 是最常见的循环方式。

例如：

```php
foreach ($products as $product) {
    echo $product['name'];
}
```

可以理解为：

```text
从 products 中
每次取出一个产品

↓

放到 $product

↓

执行一次代码
```

直到所有数据都处理完。

---

## 4. 获取数组索引

本实验使用：

```php
foreach ($products as $index => $product)
```

这样可以同时得到：

```text
$index
$product
```

例如第一条数据：

```text
$index = 0
```

但页面通常希望显示：

```text
产品 1
```

因此可以写：

```php
$index + 1
```

## 5. 循环生成 HTML

如果有三个产品，不推荐这样写：

```html
<article>产品 A</article>
<article>产品 B</article>
<article>产品 C</article>
```

更合理的思路是：

```text
准备数据
↓
foreach
↓
HTML 模板
↓
自动生成多个卡片
```

例如：

```php
<?php foreach ($products as $product): ?>

    <article>
        <h3><?= $product['name'] ?></h3>
    </article>

<?php endforeach; ?>
```

如果以后增加第 4、5、10 个产品，HTML 模板不需要修改。

只需要修改数据。

---

## 6. 三种循环如何选择

### for

适合：

```text
明确知道执行多少次
```

例如：

```text
生成 1～10
重复显示 5 次
```

---

### while

适合：

```text
不知道准确执行次数
但知道停止条件
```

例如：

```text
只要某个条件成立
就继续执行
```

---

### foreach

适合：

```text
遍历数组
```

在 PHP 网站开发中，尤其是：

```text
文章列表
产品列表
用户列表
分类列表
数据库查询结果
```

都会大量使用 `foreach`。

---

## 7. 与 WordPress 的关系

WordPress 最经典的循环：

```php
while (have_posts()) {
    the_post();
}
```

就是：

```text
只要还有文章
↓
继续处理下一篇文章
```

因此 WordPress 中著名的：

```text
The Loop
```

本质就是循环。

---

## 8. 与数据库开发的关系

以后从数据库读取多条记录：

```text
数据库
↓
获取多条数据
↓
循环
↓
生成 HTML
```

例如：

```php
foreach ($rows as $row) {
    echo $row['title'];
}
```

因此：

```text
数组
+
循环
```

是 PHP 动态页面最核心的基础组合之一。

## 本章重点

本章最重要的是理解：

```text
重复的数据
↓
不要重复写 HTML

应该：

数据
+
循环
+
一份 HTML 模板
```

最终：

```text
PHP 自动生成页面
```

这是从静态 HTML 转向动态 PHP 页面非常关键的一步。
