# 实验 07：PHP GET 参数读取

本实验通过一个极简产品搜索页，学习浏览器如何通过 URL 把数据传给 PHP。

## 实验目标

完成本实验后，应能够理解：

- 什么是 GET 请求
- 什么是 URL 查询参数
- `$_GET`
- `$_GET['keyword']`
- `??` 默认值
- `trim()`
- `stripos()`
- GET 参数如何驱动页面内容变化
- 为什么输出用户输入时要使用 `htmlspecialchars()`

## 1. 什么是 GET 参数

访问：

```text
index.php?keyword=wpc
```

可以拆成：

```text
index.php
↓
页面地址

?
↓
查询参数开始

keyword=wpc
↓
参数名 = 参数值
```

PHP 可以通过：

```php
$_GET['keyword']
```

读取：

```text
wpc
```

---

## 2. $_GET 是什么

`$_GET` 是 PHP 提供的一个超全局数组。

例如访问：

```text
index.php?keyword=wpc&page=2
```

PHP 中大致可以理解为：

```php
$_GET = [
    'keyword' => 'wpc',
    'page' => '2',
];
```

因此：

```php
$_GET['keyword']
```

得到：

```text
wpc
```

---

## 3. 为什么使用 ??

本实验写：

```php
$keyword = $_GET['keyword'] ?? '';
```

意思是：

```text
如果 keyword 存在
↓
使用它

否则
↓
使用空字符串
```

如果直接写：

```php
$_GET['keyword']
```

但 URL 中没有 `keyword`，就可能产生未定义索引相关提示。

因此：

```php
??
```

是处理可选输入时非常常见的写法。

---

## 4. trim()

本实验使用：

```php
trim($_GET['keyword'] ?? '')
```

`trim()` 会去掉字符串两侧多余空格。

例如用户输入：

```text
   WPC
```

处理后：

```text
WPC
```

---

## 5. GET 表单

HTML：

```html
<form method="get">
```

输入框：

```html
<input name="keyword">
```

用户输入：

```text
WPC
```

提交后浏览器会生成类似：

```text
index.php?keyword=WPC
```

于是形成：

```text
HTML 表单
↓
GET
↓
URL
↓
$_GET
↓
PHP
```

---

## 6. 简单搜索逻辑

本实验使用：

```php
stripos($product, $keyword) !== false
```

`stripos()` 用来查找一个字符串是否包含另一个字符串，并且不区分大小写。

例如：

```text
产品：
WPC Decking

关键词：
wpc
```

仍然可以匹配。

---

## 7. 为什么必须写 !== false

`stripos()` 找到关键词后，会返回关键词出现的位置。

例如关键词出现在最开头：

```text
位置 = 0
```

但 PHP 中：

```text
0
```

在某些条件判断中可能被当作 false。

因此正确判断应该写：

```php
stripos($product, $keyword) !== false
```

代表：

> 只要返回结果不是 `false`，就说明找到了。

---

## 8. 为什么输出 GET 参数时要转义

用户可以修改 URL：

```text
?keyword=任意内容
```

因此：

```php
$_GET
```

属于外部输入。

输出到 HTML 页面时，不应该直接：

```php
<?= $keyword ?>
```

本实验统一使用：

```php
htmlspecialchars()
```

并封装为：

```php
e()
```

例如：

```php
<?= e($keyword) ?>
```

这是非常重要的基本安全习惯。

---

## 9. GET 最适合什么场景

GET 很适合：

```text
搜索
筛选
排序
分页
分类
查看某条数据
```

例如：

```text
?keyword=php
?page=2
?sort=price
?category=decking
?id=10
```

它们有一个共同特点：

> 参数可以直接体现在 URL 中。

---

## 10. GET 的一个重要特点

GET 参数会显示在地址栏中。

例如：

```text
index.php?keyword=WPC
```

因此它特别适合：

```text
可以分享
可以收藏
刷新后仍然存在
```

的页面状态。

但不适合传递：

```text
密码
敏感信息
大量数据
```

---

## 11. 与后续分页的关系

以后分页经常写成：

```text
?page=2
```

PHP：

```php
$page = $_GET['page'] ?? 1;
```

搜索和分页还可以组合：

```text
?keyword=wpc&page=2
```

因此这一章是后面：

```text
搜索
排序
分页
数据库查询
```

的重要基础。

---

## 12. 与 WordPress 的关系

WordPress 中 URL 也大量使用查询参数。

例如后台常见：

```text
?post=123
&action=edit
```

PHP 本质上仍然是在根据请求参数决定：

```text
用户要看什么
↓
程序执行什么逻辑
```
