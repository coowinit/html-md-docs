# 快速开始

第一次使用时，建议先确认目录结构，再修改一篇 Markdown 测试文档。

## 1. 修改正文

例如打开：

```text
docs/002.md
```

直接使用 Markdown 编写内容，保存后刷新页面即可。

## 2. 新增文档

新建：

```text
docs/015.md
```

然后在 `index.html` 的 `window.DOCS_NAV` 数组中增加：

```javascript
{ title: "常见问题", page: "015" }
```

## 3. 调整分类

把二级目录项移动到另一个一级目录的 `children` 中即可，不需要修改 JavaScript 主逻辑。

## 4. 部署

推荐部署到 GitHub Pages 或任意静态 HTTP 主机。Markdown 通过 `fetch()` 读取，因此不要把 `file://` 双击预览当成正式运行方式。
