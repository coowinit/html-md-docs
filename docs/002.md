# 实验 02：PHP 数组与数据遍历

本实验通过一个简单的产品数据示例，学习 PHP 中最常见的数组结构以及 `foreach` 遍历方式。

完成本实验后，应能够理解：

- 什么是索引数组
- 什么是关联数组
- 什么是多维数组
- 如何通过键名读取数组数据
- 如何使用 `foreach` 遍历数组
- PHP 数据如何循环输出为 HTML
- 为什么 WordPress / WooCommerce 中经常会看到数组结构

## 核心知识

### 1. 索引数组

索引数组使用数字作为索引：

```php
$categories = [
    'WPC Decking',
    'WPC Wall Panel',
    'WPC Fence',
];
```

对应索引：

```text
0
1
2
```

读取第一个元素：

```php
$categories[0]
```

---

### 2. 关联数组

关联数组使用字符串作为键：

```php
$product = [
    'name'  => 'Classic WPC Decking',
    'model' => 'D01',
    'price' => 25.80,
    'stock' => true,
];
```

读取产品名称：

```php
$product['name']
```

这种结构在实际 PHP 项目中非常常见。

---

### 3. 多维数组

多个关联数组可以组合成一个产品列表：

```php
$products = [
    [
        'name' => 'Product A',
        'price' => 20,
    ],
    [
        'name' => 'Product B',
        'price' => 30,
    ],
];
```

这就是一个简单的多维数组。

可以把它理解为：

```text
产品列表
│
├── 产品 1
│   ├── name
│   └── price
│
└── 产品 2
    ├── name
    └── price
```

## foreach 遍历

`foreach` 是 PHP 中处理数组最常用的方式之一。

```php
foreach ($products as $item) {
    echo $item['name'];
}
```

在 HTML 模板中，也经常使用：

```php
<?php foreach ($products as $item): ?>

    <h3><?= $item['name'] ?></h3>

<?php endforeach; ?>
```

这种写法非常适合页面模板。

---

## 与 WordPress / WooCommerce 的关系

以后在 WordPress 或 WooCommerce 中，经常会遇到类似结构：

```php
$data = [
    'id' => 100,
    'name' => 'Product Name',
    'price' => 25,
];
```

或者：

```php
$products = [
    [...],
    [...],
    [...],
];
```

因此，理解：

```text
数组
→ 关联数组
→ 多维数组
→ foreach
```

是阅读 WordPress / WooCommerce PHP 代码的重要基础。

## 本实验中的辅助知识

### `number_format()`

用于格式化数字：

```php
number_format($price, 2);
```

例如：

```text
25.8
```

输出：

```text
25.80
```

### `htmlspecialchars()`

页面输出字符串时，对特殊 HTML 字符进行转义：

```php
htmlspecialchars($value, ENT_QUOTES, 'UTF-8');
```

本实验将它封装成简单的：

```php
e()
```

方便重复使用。

## 本章重点

这一章最重要的不是记住语法，而是建立以下认识：

```text
一条数据
↓
关联数组

多条数据
↓
多维数组

把所有数据输出到页面
↓
foreach
```

这种模式会在后续 PHP、WordPress、WooCommerce 和数据库开发中反复出现。
