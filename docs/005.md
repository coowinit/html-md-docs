## 1. 什么是函数

函数可以理解为：

```text
给一段代码起一个名字
↓
需要时直接调用
```

例如：

```php
function sayHello(): string
{
    return 'Hello PHP';
}
```

调用：

```php
echo sayHello();
```

---

## 2. 函数参数

参数就是传给函数的数据。

例如：

```php
function formatPrice(float $price): string
{
    return '¥' . number_format($price, 2);
}
```

调用：

```php
formatPrice(25.8);
```

这里：

```text
25.8
↓
传给 $price
↓
函数处理
↓
返回结果
```

输出：

```text
¥25.80
```

---

## 3. 多个参数

函数可以接收多个参数：

```php
function formatPrice(float $price, string $currency): string
{
    return $currency . number_format($price, 2);
}
```

调用：

```php
formatPrice(25.8, '$');
```

---

## 4. 默认参数

本实验使用：

```php
function formatPrice(
    float $price,
    string $currency = '¥'
): string
```

因为 `$currency` 有默认值，所以可以直接：

```php
formatPrice(25.8);
```

结果：

```text
¥25.80
```

也可以覆盖默认值：

```php
formatPrice(25.8, '$');
```

结果：

```text
$25.80
```

---

## 5. 返回值

函数通常通过：

```php
return
```

把结果返回给调用位置。

例如：

```php
function getDiscountPrice(
    float $price,
    float $discount = 0.9
): float {
    return $price * $discount;
}
```

调用：

```php
$price = getDiscountPrice(100);
```

结果：

```text
90
```

## 6. 参数类型

本实验启用了：

```php
declare(strict_types=1);
```

并使用：

```php
string
int
float
bool
```

例如：

```php

```

这里代表：

```text
$stock
应该是整数

函数返回值
应该是字符串
```

这种写法可以让代码意图更加清晰。

## 7. bool 返回值

本实验有一个函数：

```php
function isPurchasable(int $stock): bool
{
    return $stock > 0;
}
```

它只返回：

```text
true
或
false
```

因此可以用于条件判断：

```php
if (isPurchasable($stock)) {
    echo '可以买';
}
```

---

## 8. 为什么函数很重要

假设页面中有 20 个地方需要格式化价格。

如果每次都写：

```php
'¥' . number_format($price, 2)
```

以后规则变化，就可能需要修改 20 个地方。

如果封装成：

```php
formatPrice($price)
```

以后只需要修改：

```php
formatPrice()
```

函数内部即可。

因此函数最核心的价值之一是：

```text
减少重复
+
集中维护规则
```

## 10. 与 WordPress 的关系

WordPress 中大量功能都是通过函数调用完成的。

例如：

```php
the_title();
the_permalink();
get_header();
get_footer();
has_post_thumbnail();
```

当看到：

```php
get_header();
```

可以把它理解为：

```text
WordPress 已经提前定义好了一个函数

↓

我们只负责调用它
```

WordPress 本质上就是建立在大量 PHP 函数和类之上的系统。

## 11. 与 WooCommerce 的关系

WooCommerce 中也经常看到：

```php
$product->get_name();
$product->get_price();
$product->is_in_stock();
```

这里虽然已经涉及对象和方法，但思想与函数非常接近：

```text
传入数据
或
读取对象数据

↓

执行内部逻辑

↓

获得结果
```

## 本章重点

这一章最重要的是理解：

```text
重复逻辑
↓
封装成函数

输入数据
↓
参数

处理数据
↓
函数内部

输出结果
↓
return
```

因此可以形成一个非常重要的 PHP 编程习惯：

> 页面负责展示，重复的数据处理规则尽量放到函数中。
