## 1. 为什么分页必须先知道总记录数

假设：

```text
总记录 = 23
每页 = 5
```

那么：

```text
23 / 5 = 4.6
```

向上取整：

```text
5 页
```

PHP：

```php
$totalPages = ceil(
    $totalItems / $perPage
);
```

---

## 2. COUNT(*)

SQL：

```sql
SELECT COUNT(*)
FROM products
```

得到总记录数。

如果有搜索条件：

```sql
SELECT COUNT(*)
FROM products
WHERE name LIKE :keyword
```

得到：

```text
搜索结果的总记录数
```

分页必须使用过滤后的总数，而不是数据库全部记录数。

---

## 3. 当前页

URL：

```text
?page=3
```

PHP：

```php
$page = $_GET['page'] ?? 1;
```

本实验进一步使用：

```php
FILTER_VALIDATE_INT
```

确保页码是整数。

## 4. LIMIT

SQL：

```sql
LIMIT 5
```

表示：

```text
最多取 5 条记录
```

也就是：

```text
每页数量
```

---

## 5. OFFSET

例如：

```sql
OFFSET 10
```

意思是：

```text
先跳过 10 条记录
```

然后再开始取数据。

---

## 6. OFFSET 如何计算

公式：

```text
OFFSET
=
(当前页 - 1)
×
每页数量
```

例如：

```text
第 1 页
(1 - 1) × 5 = 0

第 2 页
(2 - 1) × 5 = 5

第 3 页
(3 - 1) × 5 = 10
```

PHP：

```php
$offset = ($page - 1) * $perPage;
```

## 9. 为什么 ORDER BY 不能直接这样绑定

很多初学者会尝试：

```php
ORDER BY :sort
```

然后：

```php
$statement->bindValue(
    ':sort',
    'price DESC'
);
```

这通常不是正确思路。

PDO 参数绑定主要用于：

```text
数据值
```

而：

```text
字段名
排序方向
表名
SQL 关键字
```

属于 SQL 结构。

---

## 10. 排序必须使用白名单

本实验：

```php
$sortOptions = [
    'id_desc' => 'id DESC',
    'id_asc' => 'id ASC',
    'price_asc' => 'price ASC',
    'price_desc' => 'price DESC',
    'name_asc' => 'name ASC',
];
```

用户 URL 只能传：

```text
sort=price_asc
```

程序再映射成：

```sql
price ASC
```

这就是：

```text
白名单
```

---

## 11. 为什么白名单很重要

如果直接：

```php
$orderBy = $_GET['sort'];
```

然后：

```php
$sql = "
    SELECT *
    FROM products
    ORDER BY $orderBy
";
```

就等于把用户输入直接放进 SQL 结构。

这是不安全的设计。

正确做法：

```text
用户只能选择程序预先定义的有限选项
```

---

## 12. LIMIT 和 OFFSET 为什么绑定整数

本实验：

```php
$statement->bindValue(
    ':limit',
    $perPage,
    PDO::PARAM_INT
);
```

以及：

```php
$statement->bindValue(
    ':offset',
    $offset,
    PDO::PARAM_INT
);
```

明确告诉 PDO：

```text
它们是整数
```

---

## 13. 搜索、排序、分页如何同时保留

URL 可能是：

```text
?keyword=WPC
&sort=price_asc
&page=2
```

分页链接不能只写：

```text
?page=3
```

否则：

```text
keyword
sort
```

都会丢失。

因此本实验使用：

```php
http_build_query()
```

重新生成完整参数。

---

## 14. http_build_query()

PHP：

```php
http_build_query([
    'keyword' => $keyword,
    'sort' => $sort,
    'page' => $page,
]);
```

会生成类似：

```text
keyword=WPC&sort=price_asc&page=2
```

非常适合构建 GET 查询字符串。
