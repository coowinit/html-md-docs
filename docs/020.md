# 实验 20：PHP Mini Notes 综合迷你项目

这是整个 `php-development-lab` 第一阶段的最后一个实验。

前 19 个实验的目标是分别理解 PHP 的独立知识点；本章不再增加大量新技术，而是把核心知识组合成一个小而完整的：

```text
PHP Mini Notes
```

即：

> PHP + SQLite 笔记管理系统。

---

通过一个真正可运行的小项目，把以下知识连接起来：

```sql
    updated_at = :updated_at
```

# 10. 分页

每页：

```php
$perPage = 5;
```

总记录：

```sql
SELECT COUNT(*)
FROM notes
```

总页数：

```text
ceil(
    总记录 / 每页数量
)
```

OFFSET：

```text
(当前页 - 1)
×
每页数量
```

最终：

```sql
LIMIT :limit
OFFSET :offset
```

# 11. 搜索和分页为什么要同时保留参数

如果当前：

```text
keyword=PHP
page=2
```

点击下一页时必须继续保留：

```text
keyword=PHP
```

否则搜索状态会丢失。

所以使用：

```php
http_build_query()
```

统一生成分页 URL。

# 13. HTML maxlength 不是服务器安全措施

表单同时设置：

```html
maxlength="120"
```

这是用户体验辅助。

但客户端限制可以被绕过。

所以服务器端仍然执行：

```php
textLength()
```

验证。

# 14. PDO 预处理

所有包含外部数据的 SQL 都使用：

```text
prepare()
+
execute()
```

或者：

```text
bindValue()
```

例如：

```php
$statement->bindValue(
    ':id',
    $id,
    PDO::PARAM_INT
);
```

继续保持：

```text
SQL 结构
和
数据

分开处理
```

---

# 15. 安全输出

用户输入保存到数据库之后：

```text
仍然不是可信 HTML
```

所以输出：

```php
<?= e($note['title']) ?>
```

正文：

```php
nl2br(
    e($note['content'])
)
```

顺序是：

```text
先 htmlspecialchars
↓
再 nl2br
```

---

# 16. 三层安全意识

到这里应该非常清楚：

```text
输入验证
↓
业务数据是否合法

PDO 预处理
↓
SQL 查询是否安全

htmlspecialchars()
↓
HTML 输出是否安全
```

三者不能互相替代。

---

# 17. 删除为什么使用 POST

删除会改变服务器状态。

因此：

```text
GET
```

不应该作为这个学习项目的删除方式。

本项目：

```text
POST
↓
delete.php
↓
DELETE
```

浏览器端的：

```js
confirm()
```

只是防误点击，不是安全验证。

---

# 18. PRG

新增、编辑、删除成功后：

```text
POST
↓
数据库变化
↓
header Location
↓
GET index.php
```

即：

```text
Post
Redirect
Get
```

这样用户刷新列表页时，不会轻易重复提交上一份表单。

# 20. SQLite 数据库文件安全

学习项目把：

```text
notes.db
```

放在项目目录中，便于理解和携带。

真实部署时更推荐：

```text
Web 根目录之外
```

如果必须放在公开目录，需要通过 Web 服务器配置阻止：

```text
.db
.sqlite
```

文件被直接下载。

# 本项目最终定位

这不是商业 CMS，也不是完整后台框架。

它的价值是：

> 用最少的文件和代码，把 PHP 动态网站最重要的基础知识完整串起来。

如果能够独立看懂并修改这个项目，就已经从：


进入了：

```text
理解 PHP Web 项目结构
```

的阶段。
