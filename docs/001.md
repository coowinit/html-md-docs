# 简介

这是一个轻量的 **HTML + Markdown 文档站模板**。页面负责导航和阅读体验，正文单独保存在 `docs/` 目录中。

## 核心思路

整个项目只保留最必要的四层职责：

- `index.html`：维护一级目录、二级目录、文档编号和顺序。
- `docs/*.md`：保存 Markdown 正文。
- `css/style.css`：负责电脑端、手机端和 Markdown 排版。
- `js/app.js`：负责导航、Markdown 加载、目录生成和移动端交互。

## 为什么这样设计

项目不使用 npm、构建工具、数据库或额外 JSON 索引。这样更容易长期理解、复制和维护。

### 适合的内容

- 产品使用说明
- 技术知识库
- WordPress 开发笔记
- GitHub 项目文档
- 公司内部操作指南

> 日常维护的重点只有 `index.html` 与 `docs/*.md`。
