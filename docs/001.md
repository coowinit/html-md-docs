# 01 - PHP 基础输出、变量与数据类型

这是 `php-development-lab` 的第 01 个独立实验。

本实验只解决一个问题：**PHP 最基础的数据是如何定义，并最终输出到 HTML 页面中的？**

## 实验目标

完成本实验后，应能够理解：

- PHP 代码块 `<?php ... ?>`
- 使用 `echo` 输出内容
- 使用 `$变量名` 定义变量
- 字符串、整数、浮点数、布尔值四种基础数据类型
- 使用 `const` 定义常量
- 使用 `.` 连接字符串
- PHP 与 HTML 混合输出的基本方式

## 核心知识

### 1. PHP 变量

PHP 变量以 `$` 开头：

```php
$language = 'PHP';
$lessonNumber = 1;
$price = 25.80;
$isReady = true;
```

PHP 会根据赋值内容判断当前变量的数据类型。

### 2. 基础数据类型

本实验使用四种常见标量类型：

| 类型 | 示例 | 含义 |
|---|---|---|
| String | `'PHP'` | 字符串 |
| Integer | `1` | 整数 |
| Float | `25.80` | 浮点数 |
| Boolean | `true` | 布尔值 |

数组、对象和 `null` 会在后续实验中逐步学习。

### 3. 输出内容

最基础的输出方式：

```php
echo $language;
```

PHP 也可以直接嵌入 HTML：

```php
<h1><?php echo $title; ?></h1>
```

这正是传统 PHP 页面、WordPress 主题模板等常见的工作方式。

### 4. 常量

```php
const PROJECT_NAME = 'PHP Development Lab';
```

变量可以重新赋值，而常量通常用于保存不希望在运行过程中改变的数据。

### 5. 字符串拼接

PHP 使用 `.` 拼接字符串：

```php
$summary = $language . ' ' . $version;
```

注意它与 JavaScript 使用 `+` 拼接字符串不同。

### 6. 安全输出

页面中对普通文本使用了：

```php
htmlspecialchars($title, ENT_QUOTES, 'UTF-8');
```

当前实验只需要知道它用于把文本安全地输出到 HTML 中即可。表单输入与 XSS 会在后面的表单验证实验中重点学习。

## 如何运行

PHP 文件不能像普通 HTML 一样直接双击完整运行，需要通过 PHP 环境解析。

### 方法一：PHP 内置服务器

进入当前目录后运行：

```bash
php -S localhost:8000
```

浏览器打开：

```text
http://localhost:8000
```

### 方法二：本地 PHP 环境

也可以把文件夹放到 XAMPP、WampServer、Laragon 或其他 PHP Web 根目录中访问。

## 建议修改测试

5. 自己拼接一句完整文本。
